## [0.1.0] - 2026-06-26
### Added
- Initial release of PersianScribe.
- `WhisperTranscriber` class with lazy model loading and device auto-detection.
- TXT, SRT, and optional DOCX output writers.
- Command-line interface with `transcribe` and `batch` sub-commands.
- Jupyter notebook with single-file, widget-upload, and batch modes.
- Unit test suite for configuration and writers.
